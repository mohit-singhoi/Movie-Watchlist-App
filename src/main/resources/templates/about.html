📖 Project Overview

Movie Watchlist is a full-stack Java web application built using Spring Boot. It enables users to organize their personal movie collection by storing IMDb ratings, comments, priorities, and movie links in a responsive and cloud-hosted application. The project demonstrates enterprise Java development, responsive web design, database integration, and cloud deployment.

🚀 Project Journey

🟢 Phase 1 • Initial Development

Started by building the core application using an H2 in-memory database to rapidly develop and test CRUD operations, MVC architecture, and Thymeleaf templates.

🟡 Phase 2 • MySQL Integration

Migrated to MySQL to work with a persistent relational database and gain practical experience with Spring Data JPA, Hibernate, and SQL-based data management.

🔵 Phase 3 • PostgreSQL Migration

Upgraded the application to PostgreSQL, aligning it with modern production environments and cloud deployment best practices while improving scalability and reliability.

☁️ Phase 4 • Cloud Deployment

Configured environment variables and prepared the application for deployment on Render Cloud, enabling online access with a production-ready PostgreSQL database.

🚀 Future Roadmap

Planned enhancements include Spring Security, user authentication, role-based authorization, personalized watchlists, movie search, filtering, REST APIs, Docker support, and CI/CD integration for a complete enterprise-ready application.
